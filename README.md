# Precision Dynamics in the Consciousness Debate

This repository contains the simulation code and supplementary data for the paper:
**"Where the Map Meets the Edge: Predictive Processing, Consciousness, and the Investigator’s Hyperprior"** (Salmensuu, 2026).

## Contents
- `simulations/`: Python implementations of the Source Reliability Model and Precision-Weighted Learning Rate simulations.
- `data/`: Raw results of the sensitivity analyses and illustrative researcher-result alignment database.
- `results/`: High-resolution figures generated by the simulations.

## Abstract
Predictive processing (PP) provides a comprehensive account of the structure of experience, but its application to the consciousness debate reveals a recursive epistemic trap. We demonstrate formally how investigator hyperpriors determine evidence weighting, leading to rational divergence even under shared evidence.
